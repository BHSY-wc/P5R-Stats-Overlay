# P5R 五维人物好感面板 · 安装教程

面向**第一次用**的人。从零到面板跑起来，大约 5 分钟。

> 已经装好了只想看怎么用？直接翻同目录的《使用说明.md》。

---

## 零、装之前先确认三件事

| 检查项 | 要求 | 怎么确认 |
|---|---|---|
| 系统 | Windows 10 / 11 **64 位** | 设置 → 系统 → 关于 →「系统类型」 |
| 游戏版本 | P5R PC **1.0.4** | 见下方「怎么确认游戏版本」 |
| 运行时 | **.NET 8 桌面运行时**（Desktop Runtime） | 见下方「第一步」 |

**这个面板不需要装任何 Mod**，不碰游戏目录，不用 ReLoad2，不改存档。
游戏开着就实时读内存，游戏没开就读你最新的存档 —— 两种都能用。

### 怎么确认游戏版本

Steam 库里右键 P5R → 属性 → 已安装文件 → 游戏版本号；
或者直接看游戏根目录里 `P5R.exe` 的文件版本（右键 → 属性 → 详细信息）。
**必须是 1.0.4**，其他版本内存特征码对不上，面板会显示「扫描不到五维签名」。

## 第一步：装 .NET 8 桌面运行时

### 先看有没有装过

按 `Win + R`，输入 `cmd` 回车，然后粘贴这一行：

```
dotnet --list-runtimes
```

看输出里有没有 **`Microsoft.WindowsDesktop.App 8.x.x`** 这一行：

- **有** → 跳过这一步，直接去第二步
- **没有** / 提示「不是内部或外部命令」 → 继续往下装

### 下载

官方下载页：

```
https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
```

在页面里找 **「.NET Desktop Runtime 8.0.x」** 这一栏 ——

> ⚠️ 一定是 **Desktop Runtime**（桌面运行时），不是 Console Runtime，也不是 ASP.NET Core Runtime。
> 装错了面板会闪一下就消失，什么提示都没有。

点那一栏的 **Windows / x64** 下载，得到一个 `windowsdesktop-runtime-8.0.x-win-x64.exe`（约 55 MB）。

### 安装

双击 → 下一步到底。不需要重启。

装完再跑一次 `dotnet --list-runtimes`，应该能看到：

```
Microsoft.WindowsDesktop.App 8.0.x [...]
```

---

## 第二步：解压到哪

把 `P5R五维人物好感面板_冰寒石英.zip` **整个解压出来**，得到一个同名文件夹。

推荐位置（任选，**都不影响使用**）：

```
D:\Tools\P5R五维人物好感面板_冰寒石英\
```

或者直接放桌面。

**别做这三件事**：

| ❌ 不要 | 为什么 |
|---|---|
| 在压缩包里直接双击 exe | 会解到临时目录，配置存不住，下次打开又变回默认 |
| 解压进游戏安装目录 | 没必要，还可能被 Steam 校验当成异常文件 |
| 放在 OneDrive / 坚果云同步的文件夹里 | 同步进程会锁住 `p5r_overlay.log`，偶尔写日志失败 |

文件夹里的东西长这样：

```
P5R五维人物好感面板_冰寒石英\
├─ P5ROverlay.exe            ← 双击这个
├─ P5ROverlay.dll
├─ P5ROverlay.deps.json
├─ P5ROverlay.runtimeconfig.json
├─ 启动面板.bat               ← 和双击 exe 等价
├─ 安装教程.md                ← 本文
├─ 说明文档\
│   ├─ 使用说明.md
│   ├─ 读取解析方法说明.md
│   └─ Coop好感度需求表.md
├─ 截图\
└─ 图标预览.png
```

**四个 `P5ROverlay.*` 文件必须放在同一层**，少一个都起不来。

## 第三步：第一次启动

双击 **`P5ROverlay.exe`**。

### 可能遇到 Windows 的拦截提示

**情况 A：蓝色窗口「Windows 已保护你的电脑」**

点左边 **「更多信息」** → 底部出现 **「仍要运行」** → 点它。

这个提示是因为 exe 没有买代码签名证书（个人工具都这样），不代表有毒。
源码级的读取逻辑写在《读取解析方法说明.md》里，可以自己核。

**情况 B：UAC 弹窗问是否允许**

先点「否」，按下面的权限规则处理。

### 权限规则（很重要）

面板要读游戏进程内存，**权限必须和游戏一致**：

| 游戏怎么启动的 | 面板怎么启动 |
|---|---|
| 普通双击（大多数情况） | 普通双击 |
| 右键「以管理员身份运行」 | 面板也要右键「以管理员身份运行」 |
| Steam 普通启动 | 普通双击 |

权限不一致时，面板状态行会写 **「无法打开 P5R.exe，请以管理员身份运行面板」** —— 看到这句就右键管理员跑一次。

### 启动后是什么样

默认是**收起态**：屏幕上一根细横条，写着「五维人物好感面板」，不挡视线。

- 点横条上的 `▾`，或者按 **`Num0`**（小键盘 0）→ 展开成四页面板
- 按 **`F10`** → 面板变贴图，鼠标点击直接穿透到游戏里
- 按 **`F9`** → 收进系统托盘，再按一次唤回
- 关窗口（✕）**不等于退出**，只是收进托盘；真退出用托盘图标右键 →「关闭面板」

## 第四步：确认它真的读到了

展开面板，看**五维页最下面那行状态字**：

| 状态行显示 | 含义 | 要不要处理 |
|---|---|---|
| `实时 · 进程已附加 · HH:MM:SS` | 已接上运行中的游戏 | ✅ 正常 |
| `存档 · 最后保存 HH:MM:SS` | 游戏没开，读的是最新存档 | ✅ 正常，开游戏后自动切实时 |
| `扫描不到五维签名` | 游戏版本不是 1.0.4 | 换回 1.0.4 |
| `无法打开 P5R.exe` | 权限不一致 | 面板改管理员运行 |
| `等待游戏启动` | 没找到游戏也没找到存档 | 先开一次游戏并存个档 |

五维有数字、好感页**一片空白**？那不是坏了 —— 存档里还没解锁到 4 个以上 Coop，
面板的定位下限就是这样，正常玩下去会自己出来。

## 第五步：调成自己喜欢的样子

点「设置」页，可改：不透明度、背景/文字/强调色、鼠标交互开关、刷新频率（默认 5 秒）、六个快捷键。

改完自动存进同目录的 `p5r_overlay.ini`，下次打开还在。

**关于不透明度**：拉到 100% 最清晰。P5R 风格是硬边红白色块，建议 **85%~90%**，低于 70% 红块会发灰。

---

## 更新版本

1. 托盘右键 →「关闭面板」（**必须先退出**，不然 exe 被占用覆盖不掉）
2. 用新 zip 里的四个 `P5ROverlay.*` + `启动面板.bat` 覆盖旧的
3. 保留你原来的 `p5r_overlay.ini` —— 配置不会丢
4. 重新双击启动

## 卸载

删掉整个文件夹就完事。没有注册表项、没有系统服务、没有开机自启。

唯一残留是系统托盘的图标缓存，重启资源管理器或注销一次就没了。

## 安装阶段常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 exe 闪一下就没了 | 没装 .NET 8 **Desktop** Runtime，或装成了 Console 版 | 按第一步重装，认准「Desktop Runtime」 |
| 报「找不到 api-ms-win-crt-runtime」 | 系统缺 VC++ 运行库 | 装一次 [VC++ 2015-2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| 报「另一个程序正在使用此文件」 | 面板还在托盘里没退 | 托盘右键 →「关闭面板」，再覆盖 |
| 面板出来了但一直「等待游戏启动」 | 没读到你存档 | 进游戏存一次档，按 `F8` 强刷 |
| 独占全屏下看不见面板 | Windows 分层窗口限制 | 游戏改成**窗口化 / 无边框窗口** |
| 高 DPI 屏上字很糊 | 显示缩放 150% 以上 | 已做 PerMonitorV2 感知，如仍糊，右键 exe → 属性 → 兼容性 →「更改高 DPI 设置」→ 勾「替代高 DPI 缩放行为」→ 系统（增强） |
