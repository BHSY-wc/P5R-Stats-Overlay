## 一、先搞清楚「点数」是什么

游戏里有三套数字，很容易混：

| 概念 | 说明 |
|---|---|
| **界面音符 ♪** | 你看到的 ♪♪♪，纯粹是显示用的 |
| **内部羁绊点数** | 本文表格用的就是它。**1 个基础 ♪ = 5 点** |
| **需求阈值** | 攒到该级要求的点数后，下次见面直接进 Rank 升级事件；升级瞬间清零，从该事件里新拿的点数重新开始累计 |

**影响点数的乘数**（可叠加，都是乘算）：

- 携带同阿尔卡那的人格面具 **×1.5**
- 定期考试年级前十 **×1.2**，年级第一 **×1.5**（只对秀尽学园相关角色和惣治郎有效）
- 在前一晚收到 SNS 邀请并**立刻回应** **×1.2**
- 礼物：普通 5 点 / 较好 10 点 / 高级 50 点
- 御船千早的契合度占卜、神社结缘、预告明信片等是独立加点

一次普通的 COOP 事件，选对全部选项大约能拿 **15~45 点**（考试成绩加成后 20~66）。
所以需求 10~20 点的级数常常一次见面就升，需求 55 以上的基本要见两三次。

## 四、几个规律

1. **差别极大**：同样是 8→9，东乡一二三只要 30 点，高卷杏要 67 点，芳泽霞 9→10 甚至要 80 点。所以「好感需求」不能按玩家等级或 Rank 统一估算，必须按角色查表。
2. **不是一路递增**：很多角色在 4→5 会掉到 20 点左右（龙司 30→20、杏 35→20、真 20、双叶 15），因为前一阶段的升级事件本身给分多。真正的大关在 **7→8、8→9**，以及 9→10。
3. **7→8 是「任务墙」高发段**：惣治郎、双叶、千早、岩井、武见、织田、东乡都在这一级插入印象空间委托，光堆好感没用。
4. **NPC 与队友的结构不同**：队友（战车/恋爱/女教皇/女帝/皇帝）需求相对整齐；非队友（节制/死神/倒悬者/恶魔/塔/星/命运）常在中间插人格指数或付费门槛。
5. **一些角色的好感根本没用**：吉田寅之助、三岛由辉、伊戈尔、摩尔加纳、冴、双子 —— 这六个的 Rank 完全由外部条件决定，存档里显示的点数是残留值，不用管。


阈值数据单独放在 `coop_need.py`，要改直接改那个文件即可。

因为存档里的好感点数是**清零式**的（升级当次事件得到的点数会作为下一级的起点），
所以「好感」+「下一级需要」两条一比对，就是当前这一级真正还差多少，比以前用历史最大值估算准得多。
