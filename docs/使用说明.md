# P5R 五维人物好感面板 · 使用说明

> **第一次用？先看 [安装教程.md](安装教程.md)** —— .NET 8 桌面运行时怎么装、解压到哪、第一次启动的拦截提示怎么处理。本文是装好之后怎么用。

《女神异闻录5 皇家版》PC 版的实时状态悬浮面板。直接读运行中游戏的内存，**不用装 Mod、不用重启游戏**；
游戏没开时自动读最新存档，显示最后一次保存时的状态。

- 适用版本：P5R PC **1.0.4**
- 运行环境：Windows 10/11 + **.NET 8 桌面运行时**（Desktop Runtime）
- 只读：不写游戏内存、不改存档、不联网

---

## 一、启动

双击 **`P5ROverlay.exe`**（或 `启动面板.bat`）。

启动后是**收起态**——一条横条写着「五维人物好感面板」，不挡游戏。
点 `▾` 或按 `Num0` 展开成五页面板。

> 若提示「无法打开 P5R.exe，请以管理员身份运行面板」，说明游戏和面板权限不一致：
> 游戏是管理员启动的话，面板也要右键「以管理员身份运行」。

## 二、六个页面

| 页面 | 内容 |
|---|---|
| **五维** | 顶部音符换算提示 + 5 条进度条（知识 / 勇气 / 灵巧 / 体贴 / 魅力）+ 斜切点数标签 + Lv 徽章 + 进度条上方的「还差 N ▶ 下一级」 |
| **好感** | 按「可以升级 / 继续积累 / 不看点数 / 已满级」分组，每行：角色 · 塔罗 · `R当前` + 白字「还差 N」+ 绿字「»R下一级」（两组都用黑底斜切标签）· 进度条 · 当前/需求（斜切标签）· 状态 |
| **关键** | 会改变玩法节奏、且必须主动去拿的能力与书：第三学期三条件、瞬杀、锁链勾绳、特别按摩（R10）、追加要钱、速读术…带截止日与实时达成状态，点一行跳能力表 |
| **日历** | 游戏内日期的月历，每格摊开当天白天/夜晚该做的事（自动换行）；可翻月、可缩放、点开看大号详情，`今` 一键切到整页日程 |
| **日志** | 附加进程、扫描地址、改键、穿透等运行记录（同时写 `p5r_overlay.log`） |
| **设置** | 不透明度、背景/文字/强调色、鼠标交互、刷新频率、六个快捷键、恢复默认 |

配色可整屏换：背景、文字、强调色各有 8 个预设，也能「自定义…」开调色板。

> 界面里的数字是**游戏内部点数**，不是音符数。原因：Coop 音符数封顶 3 个，
> 带同塔罗面具把 15 点抬到 22 点也还是 ♪♪♪，光看音符判断不出还差多少。

## 二·五、点开每一行看攻略

五维和好感两个页面，**每一行都可以点**（鼠标移上去会变成手型）。

### 好感页：这个角色每一级给什么

点任意角色行，弹层列出该角色 Rank 2 ~ 10（部分到 11 / 12）的**全部能力**：

```
┌──────────────────────────────────┐
│ 坂本龙司         战车 · Rank 4      │
├──────────────────────────────────┤
│ [R2] 不良少年交涉        ← 红色 = 已解锁
│      在和敌人的对话交涉破裂时，如果敌人性格…│
│ [R3] 追击                ← 红色
│ [R4] 隐形冲刺            ← 红色
│ [R6] 纸扇恢复            ← 灰色 = 还没到
│ [R7] 瞬杀
│ [R10] 觉醒
│ [剧情] 二觉              ← 金色 = 剧情触发
└──────────────────────────────────┘
```

- **红色** = 当前 Rank 已经拿到
- **灰色** = 还要继续升 Rank
- **金色「剧情」** = 二觉 / 三觉，不看 Rank 数量，随剧情触发
- **粉色爱心** = 恋爱线的关键对话选项，见下节
- 字号比页面正文放大 1.5 倍（能力名约 20px、说明约 17px），条目多时滚轮滚动，右侧有滚动条

### 好感页：送什么礼物加好感最多

弹层右上角有 **能力 / 礼物** 两个页签，点「礼物」就换成这个角色**好感 +50 的礼物清单**
（P5R 送礼分 5 / 10 / 50 三档，50 是最高档）：

```
┌──────────────────────────────────┐
│ 高卷杏       恋爱 · Rank 6   [能力][礼物]│
├──────────────────────────────────┤
│ [+50] 心型戒指                   │
│       ¥88,000 · 珠宝店 (地下商场)   │
│ [+50] 宇治抹茶布丁                │
│       ¥2,400 · 超市 (地下商场)      │
│ [+50] 玫瑰浴礼盒                  │
│       ¥3,200 · 花店 (新宿：晚上)    │
└──────────────────────────────────┘
```

- 每行：礼物名 + 价格 + 在哪买，第二行小字就是价格和店铺
- 字号、行高、徽章大小**和能力页完全一致**（同一个 1.5 倍字级），不会一换页就变小
- 点「能力」切回去，页签位置固定在 `✕` 左边，白底那个就是当前页
- 只有 17 个角色能从商店买到 +50 礼物；同伴（摩尔加纳）与剧情角色会显示「没有 +50 档的礼物记录」

数据来源：bilibili 游戏 Wiki《P5R/赠礼指南》礼物 × 角色矩阵，取 50 那一档，2026-11 整理。

### 五维页：这一级放开了什么

点任意一项（知识 / 勇气 / 灵巧 / 体贴 / 魅力），列出**被这项等级卡住的所有门槛**：

```
┌──────────────────────────────────┐
│ 勇气              Lv3 · 47 点       │
├──────────────────────────────────┤
│ [Lv2] 武见妙 Coop 开启      ← 红色，已解锁
│ [Lv3] 新岛真 Coop 开启      ← 红色
│ [Lv4] 岩井宗久 Coop 开启     ← 灰色，还差 1 级
│ [Lv5] 岩井宗久 · R7→R8
└──────────────────────────────────┘
```

也就是说：**想知道「还有什么内容是被五维卡着的」，点这一项就够了**，
不用翻攻略对照哪个人物要几点。像「枪械店老板要勇气几级才肯聊」这种问题，
点勇气这一项就能直接看到答案（4 级）。

> 这份门槛表不是单独抄的，是从好感需求里反解出来的，
> 所以和好感页显示的需求永远一致，不会出现两处对不上的情况。

这里的字号放大到页面正文的 2 倍（门槛行约 27px），一眼就能看清哪一级放开什么；
门槛多的时候滚轮滚动。

### 弹层操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 上下滚动（内容多时右侧出现细滚动条） |
| 点 `能力` / `礼物` | 好感弹层里切换「解锁的能力」和「+50 礼物清单」（五维弹层没有这两个键） |
| 点弹层外的空白 | 关闭 |
| 点弹层右上角 `✕` | 关闭 |
| 点弹层内部 | 不关闭（防止误触） |

数据来源：bilibili 游戏 Wiki 各角色「COOP对话攻略 → Rank等级提升效果」，
共 22 个角色 154 条能力，2026-11 整理。新岛冴、伊戈尔之外的剧情向 Coop 若没有能力表，
会显示「这个 Coop 没有战斗能力，随剧情推进」。

## 二·六、关键页

这一页只收**必须主动投入时间才拿得到、拿到以后玩法节奏会变**的东西，按五组排：

| 分组 | 收什么 |
|---|---|
| **结局 · 剧情** | 第三学期三条件：丸喜 R9（11/17 前，唯一硬条件）、明智 R8（11/17 前，加长结局）、霞 R5（12/22 前，只影响她自己的线） |
| **战斗 · 迷宫** | 龙司「瞬杀」R7、霞「锁链勾绳」R4、真「阴影因数分解」R7、双叶「印象空间搜寻」R2、祐介「即兴彩绘」R7、摩尔加纳「强夺秘宝」R5 |
| **时间 · 行动** | 川上「特别按摩★」R10（**不是 R5**，从异世界回来当晚还能出门）、混水摸鱼 R1、彻底混水摸鱼 R5、家事代理 R3、超级家事代理 R6 |
| **交涉 · 金钱** | 吉田「交涉术」R2（追加要钱）、募集经费 R3、人心掌握术 R8、魅力演讲术 R10；明智「打折优惠」R7 |
| **五维 · 效率** | 《图解·顿悟速读术》《因数分解学习法》《震撼灵魂的观影技巧》《游戏秘技宝典》，以及 DVD 播放机 + 怀旧游戏 |
| **挑战 · 汉堡** | 大爆炸汉堡三级挑战的成功条件（彗星 / 重力 / 宇宙巨塔）与再战收益，按当前五维等级实时判定 |

读法：

```
[竖条] 顾问官 R9：第三学期开关                      11/17 前
       丸喜拓人 · 唯一的硬条件。没到 R9，第三学期整段不会出现。  R5/9
```

- **右上红色标签** = 有截止日期，过了本周目就没了；金色标签 = 有日期但不是硬性
- **右下徽章**：`R5/9` = 现在 5 级、需要 9 级（黄色 = 还差 2 级以内，灰色 = 还差得远）；
  `R9 ✓` 绿底 = 已达成
- **左侧竖条**：分组颜色；变成浅绿色说明这条已经拿到
- **点带 Coop 的行**：直接弹出那个角色的能力表（和好感页是同一个弹层）
- **汉堡挑战那组**：右下不是 R 徽章，而是三枚五维徽章 `勇3/4` `知4/4` `灵3/4` =
  该项现在几级 / 这级挑战要求几级。绿 = 达标、黄 = 只差 1 级、灰 = 差得更多；
  三枚全绿时整行转绿。点这一组不会弹窗（没有 Coop 可看）
- 书 / 设施那几条没有 Rank，徽章位置空着，只看标题和获取地点

汉堡挑战补充（`5/6` 之后开放，在涩谷中央大街）：

| 挑战 | 要求 | 首次成功收益 | 奖励 |
|---|---|---|---|
| 彗星汉堡 | 勇气 / 知识 / 灵巧 均 R2 | 勇气♪1 知识♪1 魅力♪1 灵巧♪1 | 二等海员徽章（HP+10%）+ 汉堡×3 |
| 重力汉堡 | 勇气 / 知识 / 灵巧 均 R3 | 同上但 ♪2 | 一等海员徽章（HP+20%）+ 汉堡×5 |
| 宇宙巨塔堡 | 勇气 / 知识 / 灵巧 均 R4 | 同上但 ♪3 | 船长徽章（HP+30%）+ 汉堡×10 |
| 宇宙巨塔堡 · 再战 | 同上 | 只再给勇气♪3 | 汉堡×10 |

只卡**勇气、知识、灵巧**三项，体贴与魅力不要求（魅力是收益之一）。挑战失败也会给勇气
♪1/♪2/♪3，所以卡关时刷勇气不吃亏；白天花 1500/2000/2500 日元，**夜里一律 500**。
吃挑战会消耗一个时间段。

> 刻意**不收录**宫殿截止日期这类内容——游戏日历每天都会提示，属于自然推进，不需要提醒。

## 二·七、日历页

`日历` 页把《一周目最高难度完美日程》摊进月历，并自动对上游戏里的日期。

### 顶部一行

```
‹   2016 年 6 月 ▾   ›               今  −  ＋
游戏内 6 月 21 日（二）· 放学后
```

- `‹` `›`：翻上/下一个月；到 2016 年 4 月或 2017 年 3 月就变灰（表只覆盖这一学年）
- 点**年月**：弹出 4 月～3 月共 12 个月的选择面板，直接跳
- `今`：**整页切到游戏内今天的日程**（不是弹小窗，见下面「日视图」）
- `−`：缩成「只看日期」，格子里只有数字
- `＋`：展开成「带事项」，格子里白天、夜晚各占几行
- 鼠标滚轮：整页翻月（和手机日历一致）
- **自动跟随**：面板每 10 秒单独读一次游戏日期（跟「刷新频率」设成几秒无关）。
  游戏里睡一觉、过了一天，日历会自己翻到新的一天、红色高亮跟着走；跨月也会自动翻页
- 手动翻过月之后，标题下面会显示「已暂停跟随（点`今`回今天）」——这时候游戏过日子**不会**把你拽走，
  只更新「今天」的位置；点 `今` 就恢复跟随

### 格子的读法

- **红色格子 + 右上角「今天」**：游戏内当前日期
- 展开态：数字下方的小圆点，**红点 = 白天**、**蓝点 = 夜晚**
- 条目按格子宽度**自动换行**，一条长事项会折成两三行；格子塞不下时，末尾单独一行显示 `…`，
  剩下的点开那天看（弹层里是全的）
- 缩成只看日期时：格子下方一个红点 = 这天有安排；没有点 = 剧情/休息，没有可执行事项

### 点某一天（弹层）

按格子点开，弹层列出当天的完整安排。字号是正文的 2 倍左右，面板会跟着内容变大：

```
6 月 22 日                  星期三
┃ 白天
  杂货店买怀旧游戏
  发布预告信
┃ 夜晚
  【填字】自动取款机
  看 DVD（急诊室的阴天）
```

条目不截断，太长就换行；内容多时滚轮滚动，右侧有滚动条。点面板外或右上 `✕` 关闭。

### 日视图（整页一天的安排）

点 `今`（或任意一天点进来的弹层看不够时），整页会切成「只显示这一天的日程」，字更大、占满整屏：

```
‹  6 月 21 日（二） ▾  ›                        今  月历
现在：放学后                          滚轮切日 · 点日期选日
┃ 白天
  扔粉笔头
  金城宫殿路线确认
  双子COOP（4）
┃ 夜晚
  制作开锁工具
```

- `‹` `›`：切前一天 / 后一天，可以一路翻到 2016-04-01 ～ 2017-03-31
- 滚轮：内容放得下时直接切日，内容多时先滚动
- 点**日期标题**：弹出**这个月的日期网格**（可以 `‹` `›` 换月），点哪天就跳哪天
- `今`：回到游戏内今天
- `月历`：退回月视图，停在正在看的那一个月
- 某一段（白天/夜晚）没有安排时，会写「（这段没有安排）」，不会留空白让人以为漏读了

### 数据说明

- 覆盖 2016-04-09 ～ 2017-03-20，共 **310 天 / 676 条**；Excel 原表里空着的日子（如 2/4、2/5）显示「没有安排」
- 这是**一周目最高难度**的路线，按它打能在一周目内把五维和 Coop 做满；
  如果你已经偏离（比如某天没按表走），后面的条目只作参考，不是硬性要求
- 日期和时段是**实时读游戏内存**的；游戏没开时退回读最新存档保存时的日期，状态行会标明
- 游戏内时段映射：上午 / 白天 / 放学后算「白天」，夜晚 / 深夜算「夜晚」

## 三、快捷键（全部可改）

| 功能 | 默认 | 说明 |
|---|---|---|
| 唤出 / 收进托盘 | `F9` | 唤回时自动解除鼠标穿透 |
| 展开 / 收起 | `Num0` | 横条 ↔ 五页面板 |
| 上一页 | `PgUp` | 原来是小键盘 8，那个键让给「上选」了 |
| 下一页 | `PgDn` | 原来是小键盘 2 |
| 鼠标穿透 | `F10` | 面板变贴图，点击直接落到游戏里 |
| 立即刷新 | `F8` | 不等 5 秒，马上读一次 |

改键：设置页点键位按钮 → 按新组合键，`Esc` 取消。
字母/数字必须配 `Ctrl` / `Alt` / `Shift`（否则会抢全局输入），`F1–F24` 和小键盘可以单按。
键位被别的程序占用时会提示并恢复原键。

**穿透后怎么恢复**：按 `F10`、托盘图标右键「鼠标交互」、或 `F9` 唤回。

## 三·五、小键盘导航（不开鼠标也能翻面板）

面板**展开且没开鼠标穿透**时，小键盘被接管；收起 / 穿透 / 进托盘后立刻还给游戏，游戏里照常用小键盘。

| 键 | 作用 |
|---|---|
| `8` / `5` | 上 / 下一项 |
| `4` / `6` | 左 / 右（弹层开着时 = 切「能力 / 礼物」页） |
| `7` | 确认 / 打开 |
| `9` | 关闭 / 返回 |

各页怎么走：

- **五维**：`8`/`5` 在五项之间移，`7` 打开该项的门槛表，`9` 关掉。
- **好感**：`8`/`5` 在角色行之间移（自动跟着滚动），`7` 打开能力表，`4`/`6` 切能力 / 礼物，`9` 关掉。
- **关键**：`8`/`5` 逐条移，`7` 打开能力表。书、设施、汉堡挑战这几条没有能力表，按 `7` 不响应。
- **日历**：先在顶部按钮行（`‹` 年月 `›` `今` `−` `＋`）用 `4`/`6` 移动，`5` 进入日期网格；
  网格里 `8`/`5`/`4`/`6` 自由走，`7` 打开当天详情，`9` 关掉；在第一行按 `8` 回按钮行。
  光标停在年月标题上按 `7` 会打开选月浮层，浮层里 `4`/`6`、`8`/`5` 都能移，再按 `7` 直接跳过去。
- **日志 / 设置**：不接管方向键（设置页的滑块还是用鼠标拖）。

没有可打开的东西时按 `7` 就是没反应，不会误开别的窗口。

## 四、刷新频率

默认 **5 秒**一次，设置页可改 1 / 2 / 5 / 10 秒。

游戏没开时改成每 4 秒探测一次（不占用你设的长间隔），启动游戏后自动接上。
**不建议低于 2 秒**：单次轮询只读几百字节，频率再高没有收益，只是白增加调度开销。

**只有变化的行会动**：面板把这一次扫描和上一次逐项对比，只有数值真的变了的五维项 / 好感行
才会滑一下、数字滚一下；数值没变的行完全静止。所以静置时整页是纹丝不动的，
不会每 5 秒整片跳一次。

## 五、透明度与清晰度

设置页的「窗口不透明度」：

- **100% 最清晰**。低于 100% 是整窗 alpha 合成，一定会牺牲锐度，这是 Windows 分层窗口的限制
- P5R 风格是硬边色块，红/白/黑都要「实」，**建议 85%~90%**，低于 70% 红块会发灰

文字用微软雅黑 UI + GDI ClearType 渲染，不做位图缩放，已做 PerMonitorV2 高 DPI 感知。

## 七、注意

- 面板默认 **600×660**（收起 300×56），拖边缘可改大小，尺寸会记住
- **建议窗口化 / 无边框窗口**游戏，独占全屏下悬浮窗不显示
- 关窗口（✕）= 收进托盘，进程还在；真要退出用托盘右键「关闭面板」
- 重装/更新前先退出面板，否则 exe 被占用无法覆盖
- 换存档、多周目、游戏重启都能自动适配，不需要重开面板
- 面板**比游戏先进存档**打开也没关系：进存档后最多等一个刷新周期（默认 5 秒），
  五维、好感、日历都会自己补上（v1.2.3 起）

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 状态行「扫描不到五维签名」 | 游戏不是 1.0.4 | 换回 1.0.4 |
| 状态行「无法打开 P5R.exe」 | 权限不一致 | 面板右键管理员运行 |
| 五维有数、好感一片空 | 存档太早，解锁 Coop 不足 4 个 | 正常，属定位下限所致 |
| 面板先开、后进存档，好感/日历一直空 | 旧版只在启动时定位一次 Coop 地址 | v1.2.3 起会自己补读，等一个刷新周期即可；旧版只能重开面板 |
| 数值不动 | 游戏最小化/暂停或已退出 | 退出后走存档模式，看状态行时间 |
| 数字比游戏里旧 | 走的是存档路径 | 进游戏后会自动切实时 |
| 日历还停在前一天 | 把「刷新频率」调得很长，或手动翻过月（已暂停跟随） | 日历有独立的 10 秒心跳，最多 10 秒就会自己跳到今天；若顶部写着「已暂停跟随」，点 `今` 即可 |
| 字发虚 | 不透明度低于 100% | 拉回 85%~100% |
