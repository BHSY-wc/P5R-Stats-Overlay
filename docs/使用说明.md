# P5R 五维人物好感面板 · 使用说明

> **第一次用？先看 [安装教程.md](安装教程.md)** —— .NET 8 桌面运行时怎么装、解压到哪、第一次启动的拦截提示怎么处理。本文是装好之后怎么用。

《女神异闻录5 皇家版》PC 版的实时状态悬浮面板。直接读运行中游戏的内存，**不用装 Mod、不用重启游戏**；
游戏没开时自动读最新存档，显示最后一次保存时的状态。

- 适用版本：P5R PC **1.0.4**
- 运行环境：Windows 10/11 + **.NET 8 桌面运行时**（Desktop Runtime）
- 只读：不写游戏内存、不改存档、不联网

---

## 一、启动

双击 **`P5ROverlay.exe`**（或 `启动面板.bat`）。

启动后是**收起态**——一条横条写着「五维人物好感面板」，不挡游戏。
点 `▾` 或按 `Num0` 展开成五页面板。

> 若提示「无法打开 P5R.exe，请以管理员身份运行面板」，说明游戏和面板权限不一致：
> 游戏是管理员启动的话，面板也要右键「以管理员身份运行」。

## 二、五个页面

| 页面 | 内容 |
|---|---|
| **五维** | 顶部音符换算提示 + 5 条进度条（知识 / 勇气 / 灵巧 / 体贴 / 魅力）+ 当前点数 + Lv 徽章 + 距下一级还差多少 |
| **好感** | 按「可以升级 / 继续积累 / 不看点数 / 已满级」分组，每行：角色 · 塔罗 · Rank · 进度条 · 当前/需求 · 状态 |
| **日历** | 游戏内日期的月历，每格摊开当天白天/夜晚该做的事；可翻月、可缩放、点开看详情 |
| **日志** | 附加进程、扫描地址、改键、穿透等运行记录（同时写 `p5r_overlay.log`） |
| **设置** | 不透明度、背景/文字/强调色、鼠标交互、刷新频率、六个快捷键、恢复默认 |

配色可整屏换：背景、文字、强调色各有 8 个预设，也能「自定义…」开调色板。

> 界面里的数字是**游戏内部点数**，不是音符数。原因：Coop 音符数封顶 3 个，
> 带同塔罗面具把 15 点抬到 22 点也还是 ♪♪♪，光看音符判断不出还差多少。

## 二·五、点开每一行看攻略

五维和好感两个页面，**每一行都可以点**（鼠标移上去会变成手型）。

### 好感页：这个角色每一级给什么

点任意角色行，弹层列出该角色 Rank 2 ~ 10（部分到 11 / 12）的**全部能力**：

```
┌──────────────────────────────────┐
│ 坂本龙司         战车 · Rank 4      │
├──────────────────────────────────┤
│ [R2] 不良少年交涉        ← 红色 = 已解锁
│      在和敌人的对话交涉破裂时，如果敌人性格…│
│ [R3] 追击                ← 红色
│ [R4] 隐形冲刺            ← 红色
│ [R6] 纸扇恢复            ← 灰色 = 还没到
│ [R7] 瞬杀
│ [R10] 觉醒
│ [剧情] 二觉              ← 金色 = 剧情触发
└──────────────────────────────────┘
```

- **红色** = 当前 Rank 已经拿到
- **灰色** = 还要继续升 Rank
- **金色「剧情」** = 二觉 / 三觉，不看 Rank 数量，随剧情触发

### 五维页：这一级放开了什么

点任意一项（知识 / 勇气 / 灵巧 / 体贴 / 魅力），列出**被这项等级卡住的所有门槛**：

```
┌──────────────────────────────────┐
│ 勇气              Lv3 · 47 点       │
├──────────────────────────────────┤
│ [Lv2] 武见妙 Coop 开启      ← 红色，已解锁
│ [Lv3] 新岛真 Coop 开启      ← 红色
│ [Lv4] 岩井宗久 Coop 开启     ← 灰色，还差 1 级
│ [Lv5] 岩井宗久 · R7→R8
└──────────────────────────────────┘
```

也就是说：**想知道「还有什么内容是被五维卡着的」，点这一项就够了**，
不用翻攻略对照哪个人物要几点。像「枪械店老板要勇气几级才肯聊」这种问题，
点勇气这一项就能直接看到答案（4 级）。

> 这份门槛表不是单独抄的，是从好感需求里反解出来的，
> 所以和好感页显示的需求永远一致，不会出现两处对不上的情况。

### 弹层操作

| 操作 | 效果 |
|---|---|
| 滚轮 | 上下滚动（内容多时右侧出现细滚动条） |
| 点弹层外的空白 | 关闭 |
| 点弹层右上角 `✕` | 关闭 |
| 点弹层内部 | 不关闭（防止误触） |

数据来源：bilibili 游戏 Wiki 各角色「COOP对话攻略 → Rank等级提升效果」，
共 22 个角色 154 条能力，2026-11 整理。新岛冴、伊戈尔之外的剧情向 Coop 若没有能力表，
会显示「这个 Coop 没有战斗能力，随剧情推进」。

## 二·六、日历页

`日历` 页把《一周目最高难度完美日程》摊进月历，并自动对上游戏里的日期。

### 顶部一行

```
‹   2016 年 6 月 ▾   ›               今  −  ＋
游戏内 6 月 21 日（二）· 放学后
```

- `‹` `›`：翻上/下一个月；到 2016 年 4 月或 2017 年 3 月就变灰（表只覆盖这一学年）
- 点**年月**：弹出 4 月～3 月共 12 个月的选择面板，直接跳
- `今`：跳回游戏内当前月份，并恢复自动跟随
- `−`：缩成「只看日期」，格子里只有数字
- `＋`：展开成「带事项」，格子里白天、夜晚各占几行
- 鼠标滚轮：整页翻月（和手机日历一致）
- 手动翻过月之后，标题下面会显示「已暂停跟随」——游戏跨月也不会把你拽走，点 `今` 恢复

### 格子的读法

- **红色格子 + 右上角「今天」**：游戏内当前日期
- 展开态：数字下方的小圆点，**红点 = 白天**、**蓝点 = 夜晚**，后面是被格子宽度截断的条目，超出部分显示 `…`
- 缩成只看日期时：格子下方一个红点 = 这天有安排；没有点 = 剧情/休息，没有可执行事项

### 点某一天

弹层列出当天的完整安排：

```
6 月 22 日                  星期三
┃ 白天
  杂货店买怀旧游戏
  发布预告信
┃ 夜晚
  【填字】自动取款机
  看 DVD（急诊室的阴天）
```

条目不截断，太长就换行；内容多时滚轮滚动。点面板外或右上 `✕` 关闭。

### 数据说明

- 覆盖 2016-04-09 ～ 2017-03-20，共 **310 天 / 676 条**；Excel 原表里空着的日子（如 2/4、2/5）显示「没有安排」
- 这是**一周目最高难度**的路线，按它打能在一周目内把五维和 Coop 做满；
  如果你已经偏离（比如某天没按表走），后面的条目只作参考，不是硬性要求
- 日期和时段是**实时读游戏内存**的；游戏没开时退回读最新存档保存时的日期，状态行会标明
- 游戏内时段映射：上午 / 白天 / 放学后算「白天」，夜晚 / 深夜算「夜晚」

## 三、快捷键（全部可改）

| 功能 | 默认 | 说明 |
|---|---|---|
| 唤出 / 收进托盘 | `F9` | 唤回时自动解除鼠标穿透 |
| 展开 / 收起 | `Num0` | 横条 ↔ 五页面板 |
| 上一页 | `Num8` | |
| 下一页 | `Num2` | |
| 鼠标穿透 | `F10` | 面板变贴图，点击直接落到游戏里 |
| 立即刷新 | `F8` | 不等 5 秒，马上读一次 |

改键：设置页点键位按钮 → 按新组合键，`Esc` 取消。
字母/数字必须配 `Ctrl` / `Alt` / `Shift`（否则会抢全局输入），`F1–F24` 和小键盘可以单按。
键位被别的程序占用时会提示并恢复原键。

**穿透后怎么恢复**：按 `F10`、托盘图标右键「鼠标交互」、或 `F9` 唤回。

## 四、刷新频率

默认 **5 秒**一次，设置页可改 1 / 2 / 5 / 10 秒。

游戏没开时改成每 4 秒探测一次（不占用你设的长间隔），启动游戏后自动接上。
**不建议低于 2 秒**：单次轮询只读几百字节，频率再高没有收益，只是白增加调度开销。

**只有变化的行会动**：面板把这一次扫描和上一次逐项对比，只有数值真的变了的五维项 / 好感行
才会滑一下、数字滚一下；数值没变的行完全静止。所以静置时整页是纹丝不动的，
不会每 5 秒整片跳一次。

## 五、透明度与清晰度

设置页的「窗口不透明度」：

- **100% 最清晰**。低于 100% 是整窗 alpha 合成，一定会牺牲锐度，这是 Windows 分层窗口的限制
- P5R 风格是硬边色块，红/白/黑都要「实」，**建议 85%~90%**，低于 70% 红块会发灰

文字用微软雅黑 UI + GDI ClearType 渲染，不做位图缩放，已做 PerMonitorV2 高 DPI 感知。

## 七、注意

- 面板默认 **600×660**（收起 300×56），拖边缘可改大小，尺寸会记住
- **建议窗口化 / 无边框窗口**游戏，独占全屏下悬浮窗不显示
- 关窗口（✕）= 收进托盘，进程还在；真要退出用托盘右键「关闭面板」
- 重装/更新前先退出面板，否则 exe 被占用无法覆盖
- 换存档、多周目、游戏重启都能自动适配，不需要重开面板

## 八、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 状态行「扫描不到五维签名」 | 游戏不是 1.0.4 | 换回 1.0.4 |
| 状态行「无法打开 P5R.exe」 | 权限不一致 | 面板右键管理员运行 |
| 五维有数、好感一片空 | 存档太早，解锁 Coop 不足 4 个 | 正常，属定位下限所致 |
| 数值不动 | 游戏最小化/暂停或已退出 | 退出后走存档模式，看状态行时间 |
| 数字比游戏里旧 | 走的是存档路径 | 进游戏后会自动切实时 |
| 字发虚 | 不透明度低于 100% | 拉回 85%~100% |
